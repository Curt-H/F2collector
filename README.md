# f2dl

基于 [f2](https://github.com/Johnserf-Seed/f2) 的短视频平台媒体下载工具。**f2 已整体内置（vendored）在本仓库中并带本地增强补丁——无需 `pip install f2`，克隆即用。**

## 特性

- **短视频平台全模式下载**：one/post/like/collection/collects/music/mix/live/related/friend 共 10 种模式，f2 引擎随仓库内置
- **只保留媒体**：默认不保存文案 / 封面 / 原声 / 歌词，只要图片和视频
- **平铺存储**：不按作品建子文件夹，媒体文件直接归档在作者目录下
- **自动生成配置**：以 f2 官方默认配置为底稿，自动改写任务字段并持久化到 `dy\conf\`
- **账号级防重复**：以主页 sec_uid 为账号唯一键——重复粘贴已入库账号的链接（含带追踪参数的变体）自动复用已有任务增量追更（幂等），不产生重复配置；别名撞车（不同账号同昵称）自动加 `-1/-2` 后缀防静默覆盖；`rerun-all` 启动时对同账号多份配置告警并只跑首个
- **增量追更**：每个任务记录 `last_run` 上次运行时间；平台端自动把拉取窗口收窄为 `上次运行|今天`，已下载作品由引擎按文件存在跳过
- **双模式重跑**：单任务重跑前询问增量/全量（回车默认增量）；`rerun-all` 批次开始统一询问一次；非交互/脚本调用默认增量。增量=只拉各任务上次运行后的新作品；全量=扫描全部作品（已下载自动跳过，受 30 分钟滚动预算保护），任务配置中的日期区间原值不受影响。全量改跑剥离 `last_run` 的临时配置副本，引擎按零窗口下限真全量扫描并核对主页计数（2026-09-17 缺陷修复：此前引擎双轨语义会把全量静默截断成增量）
- **失败自动重试**：网络中断等导致的失败自动重跑整个任务（断点续传 + 跳过已完成），最多重试 2 次
- **防风控节奏**：平台请求自动携带 `uifid` 头（Argus 网关校验，上游 f2 issue #443）；批量追更任务间随机冷却 30~60 秒；任务失败冷却 60/90/120 秒逐级放大；**作品列表直接走 Firefox 真实浏览器通道**——Playwright 无头 Firefox 打开用户主页，页面 JS 在真实环境现场签名发请求，Python 旁路拦截响应，无头失败自动有头重试，不设 httpx 兜底——收紧窗口内其 8 次重试必然全 403 徒增暴露（2026-09-15 风控收紧窗口实测：httpx 8/8 全 403 时浏览器通道 4/4 全 200），数据结构与原通道完全同构、下游零改动
- **全自动滚动追更**：浏览器通道每次翻页随机 CD 5~15 秒（期间实时检查新页到达）；滚动连续失败自动换姿势重试并递增等待，会话异常终止自动续滚（最多 5 次、跨会话按作品去重），直到拉全增量窗口；**逐条精确停止**——追更任务拉到发布时间 ≤ 上次运行时刻的作品即停并剔除窗口外作品（显式区间任务按区间起点）；30 分钟总预算与续滚上限做失控保险丝；**全量核对**——主页打开时提取"作品 N"总数，全量模式已收条数达到总数才算完成，预算与续滚上限按总数动态扩展（如 682 条账号预算自动扩至 ~53 分钟），结束时核对已收与主页计数，缺口（可能含私密作品）醒目报告
- **批量追更自动重试**：`rerun-all` 整批结束后对失败任务自动重试，最多 3 轮、轮间随机冷却 60~120 秒，只重跑失败任务；cookie 环境性失败仍立即中止（环境问题重试无意义）
- **Cookie 全自动生命周期**：每个任务启动时自动从浏览器重抓 cookie（默认 Firefox，抓取前预检浏览器进程；进程内直抓 browser_cookie3，不再起 f2 子进程），经 f2 原生 --cookie 参数直传下载进程——**任务配置文件里的 cookie 字段永久留空**；批量追更批次内复用新鲜 cookie（30 分钟内免重抓、批次结束统一清空），单任务模式保持任务结束即清空。另保留 cookie 子命令与向导菜单做手动诊断/救急（浏览器抓取、粘贴、从旧 f2 配置导入）
- **启动加速（O1/O2/O3/W1）**：cookie 抓取去子进程化（每任务省 4~7 秒）；批次 cookie 复用（每任务再省 5~12 秒）；post 模式直接用作品列表自带的作者信息建目录/写库（完全省掉 profile 请求，少一次 Argus 暴露面）；浏览器实例进程内常驻复用（续滚/多会话免 3~5 秒内核冷启动）
- **交互向导**：不带参数运行即进入菜单式向导（新任务 / 重跑任务 / Cookie 管理）
- **零 Bark 推送**：已默认关闭上游的 Bark 通知（避免未配置 key 时的 405 报错）

## 安装

要求：Python 3.11+

```powershell
git clone https://github.com/<you>/f2dl.git
cd f2dl
pip install -r requirements.txt
```

作品列表下载走 Firefox 真实浏览器通道（Playwright），其浏览器内核（约 90MB）不随 git 仓库分发：克隆后双击仓库根的 `install_browser.bat` 装进项目目录 `ms-playwright\`（等价手动命令：`$env:PLAYWRIGHT_BROWSERS_PATH = "<仓库根>\ms-playwright"; python -m playwright install firefox`）。运行时代码自动优先使用项目内内核，缺失时回退系统目录——**整个项目目录（含便携 `python\` 环境与 `ms-playwright\` 内核）直接拷贝到任何电脑均可使用**。

## 使用

```powershell
python app.py                                  # 交互向导
python app.py cookie                           # 手动抓取平台 cookie（仅诊断/救急；任务启动会自动重抓）
python app.py cookie --import-f2               # 从旧版 f2 的配置导入 cookie（手动迁移用）
python app.py -u "https://www.douyin.com/user/MS4wLjAB..." -M post
python app.py -u "<链接>" -M post --gen-only   # 仅生成配置不下载
```

- 任务配置持久化在 `dy\conf\<任务>.yaml`，**重跑同一命令即增量追更**
- 同一账号重复提交是安全操作：按主页 sec_uid 自动定位已有任务追更（幂等），`last_run`、自定义高级设置与显式区间原样保留；主页链接落盘前统一清洗为无追踪参数的规范 URL
- 下载输出：`Download\<账户名>\`（配置内为相对路径，相对工具根）
- 高级选项（下载目录、命名规则、并发数等）在向导「高级设置」子菜单中调整

## 首次使用

2. 直接运行任务即可——工具会在每个任务启动时自动重抓 cookie、结束即清空，无需任何手动配置
3. 若抓取失败（浏览器未关/未登录），单任务模式会提示重试或手动粘贴；批量模式会中止整批

## 目录说明

| 路径 | 说明 |
|------|------|
| `f2/` | 内置的 f2 引擎（vendored，含本地补丁，勿手动修改） |
| `f2dl/` | 工具本体 |
| `scripts\` | 探针与验证/e2e 脚本（诊断用手动运行） |
| `utils\` | 实用工具（如关注列表导出，手动运行） |
| `ms-playwright\` | Playwright Firefox 内核（便携化；`install_browser.bat` 安装，缺失时自动回退系统目录） |
| `Download\` | 下载输出 |
| `logs\` | f2 运行日志（排障用） |
